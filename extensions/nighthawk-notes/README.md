# Nighthawk Notes

**Notice:** This extension is bundled with Nighthawk. It can be disabled but not uninstalled.

Linked Markdown notes inside the editor, in the spirit of Obsidian and Notion, with shared team spaces.

- **My Notes**: a vault of plain Markdown files (by default `~/Nighthawk Notes`; any Obsidian vault works too).
- **Links**: `[[Note]]`, `[[Note#Heading]]`, `[[Note|label]]` and `![[Note]]`, with completion, hover previews and go to definition. Clicking a link to a note that does not exist creates it. Renaming a note updates every link to it.
- **Backlinks**, **Tags** (`#tag` and frontmatter `tags:`) and a **Graph** of how notes link together.
- **Daily notes** and **templates** (`{{title}}`, `{{date}}`, `{{time}}`).
- **Blocks**: type `/` at the start of a line for headings, to-dos, callouts, tables, code, diagrams and more.
- **Teams**: sign in to a [Nighthawk Notes server](../../notes-server/README.md), create teams, invite people by link or code, give them viewer, editor, admin or owner roles, and edit the team's shared notes like any other file.
